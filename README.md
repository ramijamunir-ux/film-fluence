# 🎬 Film-Fluence | Movie Recommendation System

> A content-based movie recommendation system built using Python, Natural Language Processing (NLP), and Streamlit. Discover your next favorite film seamlessly based on plot summaries, genres, and key attributes!

---

## ✨ Features

- 🔍 **Smart Content Matching:** Recommends similar movies using TF-IDF vectorization and Cosine Similarity.
- 🎨 **Interactive UI:** Clean and responsive user interface built with Streamlit.
- 🍿 **Instant Results:** Get real-time recommendations along with movie posters and details.

---

## 🛠️ Tech Stack & Libraries

- **Language:** Python
- **Machine Learning & NLP:** Scikit-learn, Pandas, NumPy, NLTK
- **Frontend Framework:** Streamlit
- **Dataset:** TMDB 5000 Movies Dataset (Kaggle)
